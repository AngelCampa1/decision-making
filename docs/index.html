Help your agent think through a hard choice

This is a free skill file for AI coding agents. Your agent reads it when you need to make a call. It picks one of four ways to work through it.

We have not proven this works yet. No skill here has passed a real test. The scorecard is empty on purpose.

We build the measuring tools first. Every result is public. So are the ones that went badly.

What it does

Agents are bad at some choices. You hand over a pile of facts and ask what to do. The agent treats every fact as equal. It gives a big choice and a small one the same thought.

This skill helps with that. It asks one question first: what is hard here? Then it reads one guide, not all four.

What is hardWhat it does
Too many facts arrivedSorts what the choice turns on. Says what it set aside.
The advice may not fit youGives the normal answer. Then names what would change it.
You worry what it startsFollows the chain. Says what you can no longer do.
You know what to do, not whenPrices the undo. Finds the real deadline.

The point is the answer. Four neat blocks and no advice is not help. That turns your question into homework.

Install it in one line

The files are plain markdown. They follow the Agent Skills standard. That means no setup and no changes.

Claude Code

cp -r skills/* .claude/skills/

Codex, Cursor, Copilot, Gemini CLI, Cline, Amp, OpenCode

cp -r .agents/skills/* ~/.agents/skills/

There is also a Claude Code plugin. It ships nothing today. A skill only goes in once it has passed a test.

What we have measured

About 4,240 model calls so far. They all ask one thing. Does the skill turn on at the right time? None of them ask yet if it helps you choose better.

Five times we changed how the skill describes itself. Five times it made no difference. The agent was just as good at telling a real choice from normal chat. That result held up. It also turned out to be less exciting than it looked.

Our test set has a hole in it. You can pass 89% of it by counting words in the message. Long message, real choice. Short message, not a choice.

Our highest score so far is 95.6%. So every test above was fighting over about six points. We are rebuilding the test set now.

We also keep a list of the times our own tests were broken. There are eight so far. Every one ran clean and gave a number that looked fine.

Why we test at all

Lots of people share prompt packs. Almost nobody checks if they work. We wanted to know which ones help, and by how much.

So every skill runs against four versions of itself:

  • Off. No skill at all.
  • On. The real skill.
  • Filler. Same length, same shape, no real advice.
  • Think first. Just "think step by step".

Beating "off" is easy. Beating filler is the real test. A skill that only beats nothing did nothing. The extra words did the work.

We also write down what we expect before each run. The date is in the git history, so we cannot move it later. A guess made after the fact is not a guess.
