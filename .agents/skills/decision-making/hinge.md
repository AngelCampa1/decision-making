# Ask or decide

A question arrives with a piece missing. Asking for it feels careful, and is
often a way to avoid committing instead — the two feel the same from the
inside. The test is whether *this* piece would swing the answer, not whether
more information would help. If not, asking only delays an available decision.
If so, deciding now is a guess — name it as one.

## Abort if

- Nothing is missing — the answer already has everything it needs, and the
  pull to ask is hesitation, not a gap. Present-but-unweighed facts are
  `ledger.md`'s problem, not this one.
- It is a lookup with one correct answer — go find it.
- Asking costs nothing and the answer is a message away — then just ask. This
  is for when asking has a price: time, a deadline, someone unreachable again.

## Step 1 — Name the missing piece

Not "more context" — a specific fact with a shape: a number, a date, an
intention, a constraint. If you cannot name it, there is probably no gap.

Most decisions have one or two candidates; a longer list is several
present-but-unranked facts, not one absent one.

## Step 2 — Test whether it swings the answer

For each candidate, answer the decision twice — once for each plausible value.

**If the answer comes out the same both times, the fact does not matter, no
matter how unresolved it feels.** Say so, and answer now — the missing piece
was decoration on a question you could already answer.

**If the answer changes, that fact is the hinge — the decision turns on it,**
not merely interesting or on-topic. Anything that fails this test is dropped,
even if raised first.

## Step 3 — Ask, or guess out loud

Check whether each surviving fact is obtainable before the decision is needed;
if yes, ask that one question.

If not, decide anyway on whichever value seems likely, and say so. A stated
guess differs from an unstated one — the first can be corrected later, the
second gets treated as settled.

## Output

```
UNKNOWNS
  - <fact> — plausible values: <A> / <B>

HINGE TEST
  - <fact> — under <A> the answer is <X>, under <B> it is <Y> → hinge
  - <fact> — same answer either way → dropped

THEREFORE
  ask:    <the one question worth asking, if any>
  decide: <the answer now, flagged as conditional on <guessed value> if needed>
```

If nothing survives Step 2, say the answer, and say why: the missing piece
would not have changed it.
