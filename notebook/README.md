# Research log

Append-only. Entries are dated and never edited after the fact — if something
here turns out to be wrong, a later entry says so and links back. Rewriting an
entry to look smarter in hindsight would destroy the only thing this directory is
for.

The log records three things that the code cannot:

1. **Predictions made before runs.** A prediction written down before the data
   arrives is evidence; the same claim written afterwards is a story.
2. **Dead ends.** Approaches that failed and why, so they aren't re-attempted and
   so the methods section is honest about the path taken.
3. **Why decisions changed.** Particularly where new literature overturned an
   earlier choice.

Naming: `YYYY-MM-DD-<slug>.md`.
